2025 Featured Project

NLP-Based Sentiment Analysis of Twitter & Reddit Discussions

Built a complete machine learning pipeline to classify social media sentiment at scale. Collected data from Twitter and Reddit, cleaned and processed 44,889 rows, engineered TF-IDF features, and trained three models (Logistic Regression, Naive Bayes, Linear SVM). The Linear SVM outperformed — achieving 85.9% accuracy and 85.7% F1 score across three sentiment classes. Built in Python on Google Colab.
